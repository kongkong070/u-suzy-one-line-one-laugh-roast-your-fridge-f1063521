## Entry

> My fridge hums all night like it's pulling a double shift, yet the milk still goes off on a Tuesday out of pure spite.

A single line (118 characters) roasting my fridge, written by `main.ts`
(Node 22 stdlib only) to `/output/entry.txt`. The program validates the
line against the gate — 1 to 200 characters, one line, not only
whitespace, and about a fridge — before writing it.

## Run

```sh
node --experimental-strip-types main.ts
```

`MAKEFUN_OUTPUT_DIR` overrides the output directory (default `/output`).
